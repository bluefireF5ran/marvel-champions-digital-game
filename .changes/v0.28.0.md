## [v0.28.0] - 2026-10-19
### Added
* Every release's notes thank the GitHub users who reported or wrote its changes, and the README has Special thanks lists with everyone's avatar (#268).
### Changed
* The campaign roster's seat picker lists the top five recommended partners best first (seat 1 included), then every available hero A to Z, then locked or already-seated heroes A to Z under their own heading.
### Fixed
* A hero's name, deck note and reason no longer go blank in the campaign roster's seat picker after a finger touches their row (#272).
* A sideways swipe across a row of a scrolling list no longer picks that row.
* The in-game bug report link now fills only a Game details box, so edits on GitHub's Bug report form stay put and the screenshot box takes images again (#273).
### Docs
* A Rules authority page gives the order rules sources win in when they disagree, how conflicts are resolved, and links every Rules Reference version and FFG rulings page.
