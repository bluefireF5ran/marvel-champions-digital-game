## [v0.33.0] - 2026-10-21
### Added
* Every pull request now builds an Android preview APK next to its Netlify preview, signed with the release key so testers can install it over the app, and links it in a PR comment (#328)
### Fixed
* Organizational Support's payment strip shows one tile per S.H.I.E.L.D. card it can exhaust, which you tap to build the set, instead of one tile for every combination (#326).
* Scrolling menus and the hand no longer lag behind the finger on high-resolution phones at Native or 720p: rectangular clips now use the GPU's scissor test instead of three full-screen passes a frame (#328)
* Peek at table's banner is now one slim band with a Move button that puts it at the top or the bottom of the table, so it no longer sits on the main scheme or the first enemy on a phone (#329)
* Thwart events like Multitasking can no longer be played while you cannot thwart (Baron Zemo engaged with you), and a move whose target choice found nothing can be undone again (#330)
* On a phone, a swipe of the play area that lifts over its ‹ › arrows no longer pages the row, and a drag that starts anywhere in the play area (or the phone's hand strip) scrolls it, not only one that starts on a card.
* The game no longer repaints a frame that looks the same as the last one, and draws without 4x multisampling at 2x density and up, so a high-resolution phone's GPU isn't kept busy while you read or scroll (#328)
* Make the Call now defeats an Ant-Man or Wasp ally it puts into play at 0 hit points, and resources overpaid for their cost through Make the Call now give them pym counters (#335).
