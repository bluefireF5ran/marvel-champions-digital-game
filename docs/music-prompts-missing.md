# Music prompts for every empty slot (2026-10-10)

Every scenario and campaign slot in `music/` that has no track today, in the same format as the last wave's prompts.
53 tracks: 23 for wave 9 and 30 for earlier boxes. The titles here are the ones to use for the files and the
`TRACK_TITLES` entries, whatever name the generator gives the download. None repeats a title already in the jukebox.

## How to use

One track per request. Paste the **shared block**, then **one length line**, then **one scenario description**, and say
which of the three it is, then the **title line** with that track's title. Do the battle track first; for the other two
of the same scenario, stay in the same chat and add:

```text
Use the same main melody and instruments as the battle track I just generated.
```

## Shared block (start of every request)

```text
Generate an instrumental music track. No vocals, no sung or spoken words.
Style: orchestral-hybrid film score (full orchestra plus synths and heavy
percussion), in the mood of 1990s animated superhero shows and modern
comic-book films. Original music only; do not imitate any existing theme.
I will give you the exact title for this track at the end of this request.
Use that title, word for word, as the track's name and as the file name.
Do not invent, change or add to the title.
```

## Length lines (add the one that fits)

```text
Battle: about 3 minutes, steady high energy from the first bar, no quiet intro, ends so it can loop.
```

```text
Villain wins: about 75 seconds, slow and heavy, the same theme turned dark, ends unresolved.
```

```text
Heroes win: about 75 seconds, tension releasing into a warm major-key resolution with a clear final chord.
```

## Title line (end of every request)

```text
Title: "<the track's title from the list below>"
```

If the generator names it something else, reply in the same chat:

```text
Rename this track. Its title is exactly "<the title>". Use that as the name and file name.
```
