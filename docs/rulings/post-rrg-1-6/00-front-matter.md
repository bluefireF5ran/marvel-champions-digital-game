On this page you’ll find some of the latest FFG rulings for Marvel Champions post-RRG 1.6 (the week of July 23, 2024). [All prior 1.0-1.4 questions and responses can be found on this main page, along with errata](https://hallofheroeslcg.com/official-ffg-rulings/). All [1.5 and beyond questions can be found here](https://hallofheroeslcg.com/latest-ffg-rulings-post-rrg-1-5/).

To create a link to a specific ruling, [just use this format](https://hallofheroeslcg.com/latest-ffg-rulings-post-rrg-1-6/#1) and note the number at the start of the question. Note that some numbers may not be accounted for as a result of being pulled for [outdated/legacy rulings](https://hallofheroeslcg.com/marvel-champions-lcg-legacy-rulings/).

If you have a verifiable answer from FFG for this page, email us at hallofheroescontact(at)gmail.com.
