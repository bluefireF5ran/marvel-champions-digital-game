Set it up on your first device

  1. Open the sync screen

    Choose Set up when the game asks "Set up cross-device sync?", or go to Settings → More → Save data → Sync across devices at any time.

  2. Save your recovery code

    The game shows a 25-character recovery code, like ABCDE-FGHJK-MNPQR-STUVW-XYZ23. Write it down or keep it in a password manager before you continue. It's the only way back into your saves if you lose every device.

  3. That's it

    This device now syncs by itself. It sends your changes a few seconds after you play or edit, and when you put the game away, and it fetches the latest from your other devices when the game opens or comes back to the front.

If you chose Not now, nothing changes: your saves stay on this device as before, and you can turn sync on later from the same Settings screen.

Add another device

On a device that already syncs, open Settings → More → Save data → Sync across devices → Link another device. Then, on the new device, choose Join with a code and use one of these:

Easiest

Scan the QR code

Point the new device's camera at the QR code. The game opens and asks "Join this device to your synced saves?"

No camera

Type the link code

Type the code shown beside the QR code, like ABCD-EFGH 1234-5678. It works once and expires after 15 minutes.

Any time

Type the recovery code

The 25-character code from setup always works, even when no other device is at hand.

Already have saves on the new device? They're merged with your synced saves, not wiped. If the same game was played on both, you choose which copy to keep.

Your recovery code

  • Anyone with this code can open your synced saves, so keep it private, just like a password.
  • Nobody can reset it for you. We can't read your saves, so we can't recover them either.
  • Lost it but still have a synced device? Your saves are fine. Open the sync screen there and choose Show recovery code, and link new devices from that one.

Pick up where you left off

Games in progress on any of your devices show up together under In-progress games on the title screen. Each one shows the scenario and heroes, the round, when it was last played, and where:

Browser Windows macOS Linux Android / iOS

Tap Resume to carry on. If the game is further along on another device, it fetches those moves first, so you continue exactly where you stopped. Continue picks up the newest one. You can keep several games going at once, and Remove takes one off the list on every device.

When two devices played the same game

If you kept playing one game on two devices while they were offline, they no longer match. The game notices and asks which copy you want, and never throws one away without asking:

  • Keep this device: keep the copy you're holding.
  • Keep the other device: keep the synced copy.
  • Keep both: keep them side by side as two games. Campaign games can't be split, so for those you pick one.

If the clash is in a different game from the one you're playing, the question waits until you leave the table. Decks and other saves simply keep the most recent change.

Different game versions

Your devices don't need to be on the same version. The web version updates straight away, while the Android and desktop apps update when you install the new version.

  • A game last played on a newer version shows "Played on a newer version: update to continue" on older devices, instead of opening with rules that don't match.
  • Anything an older version doesn't understand is kept safely and passed along untouched.
  • The sync screen says "Another device has a newer version of the game" when it's time to update.

Why there's no login

Most games sync with an account. We chose not to, on purpose:

  • Nothing stands between you and the game. It has always been playable straight away, with no sign-up, and sync keeps it that way. It's optional, and the game works the same without it.
  • We don't hold your personal details. With no account there's no email address, name or password to store, leak or sell. The server never learns who you are.
  • Your saves stay yours. An account usually means the server can read your data. Here, the key that unlocks your saves lives only on your devices and in your recovery code, so even we can't open them.
  • It suits a free fan project. Accounts bring password resets, account recovery, sign-in providers and data-deletion requests. Skipping all that keeps the service small, free to run, and focused on the game.
  • Your saves never depend on it. Everything lives on your device first. If the sync service is ever down or gone, nothing you've played is lost.

The trade-off: with no account, there's no "forgot password" button. Keep your recovery code safe. If you lose it and every synced device, nobody can get those saves back. An optional sign-in may come later for players who would rather have one.

Privacy and security

  • Encrypted before upload. Your device encrypts your saves before sending them. The sync server stores only scrambled data plus a few sizes and version numbers. It can't see your decks, games or settings, and your recovery code is never sent.
  • No account. There's no email, name or password. Your recovery code, and the devices you've linked, are what open your saves.
  • Where it lives. Encrypted saves are stored by a small sync service on Cloudflare's network, separate from the game's website.
  • About the typed link code. The QR code and the recovery code are fully strong. The short typed code is a convenience. It works once, expires in 15 minutes, and locks after 5 wrong tries, which stops anyone guessing it. Because the 8-digit key is short, though, someone who controlled the sync server during those 15 minutes could in theory work it out. If that matters to you, link with the QR code or the recovery code instead.
  • Not synced: settings that belong to one device, such as display, window size, volume and power saving.

Stop syncing

  • Unlink this device stops syncing here. Your saves stay on this device, and your other devices carry on.
  • Delete cloud data erases your synced saves from the server for every device. The game asks you to confirm first. Each device keeps its own local copy.

Both are in Settings → More → Save data → Sync across devices.

Help

The code didn't work

Link codes work once and expire after 15 minutes. Make a fresh one on the linked device and try again. After 5 wrong tries, the code is locked for safety. A recovery code doesn't expire; check it for typos.

My game doesn't show on the other device

Open the game on the device where you last played, so it can send its changes, then reopen the game on the other device. You can also press Sync now on the sync screen.

It says "Online sync is unavailable right now"

The sync service is paused or has reached its daily limit. Keep playing; your changes are saved here and will sync later. File export in Save data still works.

It says "Offline, changes waiting"

You have no connection right now. Your changes are kept and sent the next time you're online.

It says "Cloud data not found"

The cloud copy was deleted, from another device or after a year unused. Your saves on this device are fine. Set up sync again to start a new cloud copy.

I switched phones and lost the old one

On the new phone, choose Join with a code and type your recovery code. Without the recovery code or another synced device, synced saves can't be recovered.

Can I still move saves without sync?

Yes. Settings → More → Save data still has Send to another device for a one-time copy, and file export and import.
